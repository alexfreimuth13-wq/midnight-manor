# Midnight Manor

A mobile-first haunted carnival slot-game prototype using play credits only.

## Run locally
Open `index.html` in a modern browser.

## GitHub Pages
This repository is static-site ready. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Notes
- 5×3 reels
- Ringmaster WILD
- Fortune-Teller bonus presentation
- Mobile/iPhone-focused layout
- Animated haunted-carnival atmosphere

No deposits, purchases, withdrawals, or cash prizes are implemented.
